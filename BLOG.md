# Introducing n8n-nodes-arweave: Permanent Storage Meets Workflow Automation

We're excited to announce the release of n8n-nodes-arweave, a powerful new community node that brings Arweave's permanent storage capabilities directly into your n8n workflows.

## The Problem with Temporary Storage

In today's data-driven world, businesses face a critical challenge: ensuring long-term data preservation without recurring costs or the risk of data loss. Traditional cloud storage solutions require ongoing subscriptions, and data can disappear if payments lapse or providers shut down. For organizations dealing with compliance records, NFT metadata, audit trails, or any critical data that must remain accessible indefinitely, this creates significant risk.

## Enter Arweave and n8n

Arweave is a revolutionary blockchain-based storage network that offers truly permanent data storage with a one-time payment. By integrating Arweave with n8n's workflow automation platform, we've created a seamless solution for automating permanent data storage operations.

## Key Features

The n8n-nodes-arweave node comes packed with essential functionality:

**Data Upload & Retrieval**: Easily upload files or data to Arweave's permanent storage and retrieve them when needed. Perfect for archiving important documents, storing NFT assets, or preserving compliance records.

**GraphQL Integration**: Query Arweave's decentralized database using GraphQL to find and filter transactions based on tags, owners, dates, and more. This makes it simple to build dynamic workflows that respond to on-chain data.

**SmartWeave Contract Support**: Interact with Arweave's SmartWeave smart contracts to build decentralized applications and automate complex blockchain operations without writing code.

## Getting Started

Installing the node is straightforward. Simply run:


npm install n8n-nodes-arweave


Once installed, restart your n8n instance, and you'll find the Arweave node available in your node palette.
